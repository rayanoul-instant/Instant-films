# Instant Films

Plateforme de diffusion de courts métrages — React, Vite, Supabase, Tailwind CSS.

## Stack

- **Frontend** : React 18, TypeScript, Vite
- **UI** : Tailwind CSS, shadcn/ui, Framer Motion
- **Backend** : Supabase (auth, base de données, stockage)
- **Routing** : React Router v6

## Lancer en local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
